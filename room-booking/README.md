# 장소 예약 시스템 (Google Apps Script)

동아리실·요가실 등 학교 공간을 학생(팀)이 예약하는 웹앱입니다. 로그인 정보는 모두 스프레드시트에서 관리합니다.

## 파일 구성
| 파일 | 역할 |
|---|---|
| `Code.gs` | 서버 로직 (로그인, 예약/취소, 규칙 검사, 교사용 달력) |
| `Index.html` | 화면 뼈대 (로그인 + 메인) |
| `Style.html` | 디자인 (카드형 + 시간표형, 항상 밝은 화면, 인쇄용 A4 가로) |
| `Script.html` | 화면 동작 |
| `appsscript.json` | 시간대 `Asia/Seoul`, 웹앱 배포 설정 |

## 처음 설치 (약 10분)
1. 구글 드라이브에서 **새 스프레드시트**를 만듭니다.
2. 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
3. 파일을 만들어 내용을 붙여넣습니다.
   - 기존 `코드.gs` → 내용을 `Code.gs`로 교체
   - 파일 추가(＋) → HTML → 이름 `Index`, `Style`, `Script`
   - 프로젝트 설정(톱니바퀴) → **"appsscript.json" 매니페스트 파일 표시** 체크 후 내용 교체
4. 스프레드시트를 새로고침하면 메뉴 **예약시스템**이 생깁니다. **① 초기 설정**을 실행하세요.
5. 아래 시트를 채웁니다 (예시 행은 지우세요).
6. **배포 → 새 배포 → 웹 앱**: 실행 사용자 **나**, 액세스 **모든 사용자** → 웹 앱 URL을 학생에게 안내

## 이미 쓰고 있다면 (업데이트)
1. 5개 파일 내용을 새 것으로 모두 교체하고 저장
2. 스프레드시트 새로고침 → **예약시스템 → ① 초기 설정** 다시 실행
   (새 시트 `장소`, `설정`이 생기고, 기존 예약의 장소가 번호로 자동 연결됩니다. 기존 데이터는 지워지지 않습니다.)
3. **배포 관리 → 편집(연필) → 새 버전 → 배포**

## 스프레드시트 시트 설명
| 시트 | 내용 |
|---|---|
| `학생` | 아이디(**본명**) / 비밀번호 / 이름 / 팀명 / 역할 |
| `장소` | 번호(수정 금지) / 장소명 / 사용(O·X) |
| `설정` | 사이트제목, 아침·점심·방과후 최대횟수 |
| `휴무일` | 날짜 / 사유 / 시간대(비우면 하루 전체) |
| `예약` | 자동 기록 (직접 수정하지 마세요) |
| `로그` | 로그인·예약·취소 기록 |

**역할 칸**: `학생` / `매니저` / `학생+매니저` / `교사`
- 학생: 예약, 내 예약, 비밀번호 변경
- 매니저: **예약 달력 출력 탭만** (조회 전용, 예약·취소·휴무일 불가)
- 학생+매니저: 학생 기능 + 예약 달력 탭 (대표 학생이 자기 팀 예약도 해야 할 때)
- 교사: 예약 달력 출력, 예약 관리(대리 예약/취소), 휴무일 관리

**장소 추가/이름 변경**: `장소` 시트에서 장소명만 고치면 됩니다. 새 장소는 다음 줄에 이름만 적으면 번호(P3…)가 자동으로 붙습니다. 사용 칸을 `X`로 하면 숨겨집니다. 번호는 바꾸지 마세요. (이름을 바꿔도 지난 예약은 새 이름으로 이어집니다.)

**사이트 제목**: `설정` 시트 `사이트제목`의 값을 바꾸면 로그인 화면, 상단, 브라우저 탭 제목이 바뀝니다.

**휴무일 형식**: 연도를 포함해 `2026-12-04` (`2026.12.04`, `2026/12/04`도 가능). 시간대 칸에 `아침`/`점심`/`방과후`를 적으면 그 시간대만 막히고, 비우거나 `전체`면 하루 전체가 막힙니다. 교사 화면의 🚫 휴무일 탭에서도 등록할 수 있습니다.

## 규칙
- 예약 가능 기간: 대상 주의 **전주 토요일 08:00 ~ 일요일 18:00 (KST)**. 이 기간에만 예약·취소·재예약 가능
- 시간대: 아침 08:00~08:20 / 점심 12:30~13:10 / 방과후 월·수·금 15:00~16:30, 화·목 16:00~16:30
- 팀당 **주당** 아침·점심·방과후 각각 최대 2회 (`설정` 시트에서 변경)
- 같은 팀은 같은 날 같은 시간대에 한 곳만 예약 가능, 한 자리는 선착순 1팀, 취소는 **본인 예약만**
- 학생에게는 다른 팀 이름이 보이지 않고 "다른 팀"으로만 표시됩니다.
- 교사·매니저 달력과 교사 예약 관리 화면에서는 팀마다 다른 파스텔 색(12가지)이 자동으로 붙습니다. 색은 `학생` 시트에 팀이 처음 나온 순서대로 정해지고, 연두 계열은 11~12번째 팀에만 쓰입니다. 팀이 12개를 넘으면 색이 처음부터 다시 쓰입니다.

## 보안
- 시트는 **교사만 열람**하도록 공유하지 마세요. 학생에게는 웹앱 주소만 알려줍니다.
- 메뉴 **예약시스템 → ② 비밀번호 암호화**로 시트의 비밀번호를 암호화(해시)할 수 있습니다. (암호화 후에는 원래 비밀번호를 볼 수 없습니다)
- 로그인 5회 실패 시 10분 잠금, 로그인 6시간 유지.
- 아이디는 본명이므로 같은 이름이 있으면 `김민준A`처럼 구분해야 합니다.

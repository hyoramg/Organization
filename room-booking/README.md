# 동아리실 · 요가실 예약 시스템 (Google Apps Script)

## 파일 구성
| 파일 | 역할 |
|---|---|
| `Code.gs` | 서버 로직 (로그인, 예약/취소, 규칙 검사, 교사용 달력) |
| `Index.html` | 화면 뼈대 (로그인 + 메인) |
| `Style.html` | 디자인 (카드형 + 시간표형, 다크모드, 인쇄용 A4 가로) |
| `Script.html` | 화면 동작 (예약 팝업, 카운트다운, CSV, 인쇄) |
| `appsscript.json` | 시간대 `Asia/Seoul`, 웹앱 배포 설정 |

## 설치 순서 (약 10분)
1. 구글 드라이브에서 **새 스프레드시트**를 만듭니다. (이름 예: `동아리실 예약`)
2. 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
3. 파일을 만들어 내용을 붙여넣습니다.
   - 기존 `코드.gs` → 내용을 `Code.gs`로 교체
   - 파일 추가(＋) → HTML → 이름 `Index`, `Style`, `Script` (확장자 `.html`은 자동)
   - 왼쪽 톱니바퀴 **프로젝트 설정 → "appsscript.json" 매니페스트 파일 표시** 체크 후 `appsscript.json` 내용 교체
4. 저장 후 스프레드시트를 새로고침하면 메뉴 **예약시스템**이 생깁니다.
   **예약시스템 → ① 초기 설정**을 실행하세요. (권한 승인 필요: 고급 → 이동)
   `학생`, `예약`, `휴무일`, `로그` 시트가 만들어지고 예시 계정 3개가 들어갑니다.
5. `학생` 시트에 학생 정보를 입력합니다 (예시 행은 지우세요).

   | 아이디 | 비밀번호 | 이름 | 팀명 | 역할 |
   |---|---|---|---|---|
   | 한글/영문/혼합 가능 | 자유 | 표시 이름 | 같은 팀은 같은 이름 | `학생` 또는 `교사` |

   교사 계정은 역할을 `교사`로, 팀명은 비워 둡니다.
6. Apps Script에서 **배포 → 새 배포 → 유형: 웹 앱**
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자** (학생은 구글 계정 없이 접속)
   - 배포 후 나오는 **웹 앱 URL**을 학생들에게 알려주세요.
7. 코드를 수정한 뒤에는 **배포 관리 → 편집(연필) → 새 버전**으로 다시 배포해야 반영됩니다.

## 규칙 (코드 상단 `Code.gs`에서 변경 가능)
- 예약 가능 기간: 대상 주의 **전주 토요일 08:00 ~ 일요일 18:00 (KST)**. 이 기간에만 예약·취소·재예약 가능
- 팀당 **주당** 점심 최대 2개, 점심+방과후 합쳐 최대 4개 (`LIMIT`)
- 같은 팀은 같은 날 같은 시간대에 한 곳만 예약 가능
- 한 자리(날짜·장소·시간대)는 선착순 1팀, 취소는 **본인 예약만**
- 시간: 점심 12:30~13:10 / 방과후 월·수·금 15:00~16:30, 화·목 16:00~16:30

## 기능
- 학생: 주간 예약 시간표, 마감 카운트다운, 우리 팀 현황(점심 x/2, 합계 y/4, 누가 언제 예약했는지), 내 예약 목록, 비밀번호 변경
- 한도 초과·중복 시 **팝업**으로 사유와 팀 예약 내역 표시
- 교사: 예약 달력 출력(장소×시간대, 팀·예약자 표시, 인쇄/PDF, CSV), 대리 예약·취소, 휴무일 등록
- 보안: 로그인 5회 실패 시 10분 잠금, 로그인 6시간 유지, 팀/계정 변경 즉시 반영

## 비밀번호 보안
- 시트는 **교사만 열람**하도록 공유하지 마세요. 학생에게는 웹앱 주소만 알려줍니다.
- 더 안전하게: 메뉴 **예약시스템 → ② 비밀번호 암호화**로 시트의 비밀번호를 암호화(해시)할 수 있습니다.
  (암호화 후에는 시트에서 원래 비밀번호를 볼 수 없습니다. 재설정은 새 비밀번호를 평문으로 입력 후 다시 실행)
- 학생은 앱에서 직접 비밀번호를 바꿀 수 있고, 바꾼 비밀번호는 자동으로 암호화되어 저장됩니다.
